# Portfolio V2 개발 안내

`develop`에서 작업하고, 승인된 변경을 `main`에 병합하면 GitHub Pages가 저장소 루트를 배포합니다. 진입점은 `index.html`입니다.

## 로컬 확인

저장소 루트에서 다음 명령을 실행한 뒤 브라우저에서 http://localhost:8000/jiniee-portfolio-v2/ 를 엽니다. 저장소 폴더 이름은 jiniee-portfolio-v2를 사용합니다.

```sh
git switch develop
python3 -m http.server 8000 --bind 127.0.0.1 --directory ..
```

공개 페이지에는 저장소 이름이 경로에 포함되므로 내부 링크와 자산 경로는 문서 기준 상대 경로로 작성합니다. 승인된 화면부터 구현하고, 데스크톱과 390px 모바일에서 탐색·미디어 재생·키보드 포커스·모션 감소 설정을 확인합니다.

## 작품 자료

작품별 원본과 승인 이력은 프로젝트 공용 소스에서 관리합니다. 이 공개 브랜치에는 사용 범위가 확인된 웹용 파일만 추가합니다. 새로 만든 합성·목업은 실제 결과물과 구분해 기록합니다.
